```

  ✗ 失去 24 萬/年租金

```

## 9. 退休後動態用錢 SOP

### 核心原則
> **「200MA 決定資金來源, LTV 決定能借多少」**

### 場景 A: 200MA 站上 (60-70% 時間)

```
每月 ~20 萬支出:
  60% 質押 borrow (Lombard, 利率 2.5%)
  30% 投資池配息
  10% 現金 buffer (緊急)
  0%  賣股 ← 絕不
```

### 場景 B: 200MA 跌破 (30-40% 時間)

```
立即:
  • 換 30% 持股 + 70% 現金 (200MA 規則)
  • 停止質押 borrow

資金來源:
  70-80% 換倉現金
  20-30% 720 萬 buffer
```

### 場景 C: 大額支出 > 100 萬

```
依 LTV:
  < 20%  → 純質押
  20-25% → 一半質押 + 一半現金
  > 25%  → 純 buffer
```
